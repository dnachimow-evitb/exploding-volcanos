Privacy Policy

Exploding Volcanoes in the Bathtub  ·  Last updated November 26, 2026

The short version: the game does not collect anything about you or your child. In the optional Multiplayer mode, a few game details are shared with the other player.

What the game collects

Nothing. The iPhone app and the web game have:

  • no accounts, sign-ups or logins
  • no ads
  • no analytics or tracking
  • no in-app purchases (coins are earned only by playing)
  • no chat and no links to social media. The only sharing feature is the Multiplayer invite link, which you send yourself.

What is saved, and where

The game saves player names, toys, coins, badges and scores so they are there next time. This is stored only on the device you play on, and we cannot see it. It is never sent to us or to anyone else, with one exception: in a Multiplayer game, a few details are sent to the other player (see Multiplayer below). Player names are whatever you type in (up to 10 letters); they do not have to be real names.

Deleting the app, or clearing the website's data in your browser, erases this saved progress.

The website

The web version of the game is hosted on GitHub Pages. Like most web hosts, GitHub may record technical details such as IP addresses in its server logs when a page is loaded. We do not have access to those logs. See GitHub's privacy statement. The iPhone app today does not load anything from the internet while you play.

Multiplayer

Multiplayer is an optional online mode in the web game. The iPhone app does not have it today. The main game, and playing against the computer, work as before: nothing leaves the device.

In a Multiplayer game, two devices play each other. Their messages go through a small relay service we run on Cloudflare. The relay only passes messages between the two devices while they play. It stores nothing.

During a match, the other player gets your player's toy picture, what Noah is wearing, which toys are in the match, and the moves of the game. In a game started with a code, each player's name is sent to the other. In Quick Match, which pairs you with whoever else is waiting, names are not sent or shown.

There is no chat. Nothing can be typed to the other player.

To invite a friend, the game shows a four-letter code. It can also open your phone's share sheet with a link containing that code. The game does not see who you send it to.

Like any web service, Cloudflare may record technical details such as IP addresses when a device connects. We do not use these for anything. See Cloudflare's privacy policy.

Children

The game is made for families and young children. Because it collects no personal information from anyone, it collects none from children.

Changes

If this policy changes, the new version will be posted on this page with a new date.
