Privacy Policy

Exploding Volcanoes in the Bathtub  ·  Last updated November 13, 2026

The short version: the game does not collect anything about you or your child.

What the game collects

Nothing. The iPhone app and the web game have:

  • no accounts, sign-ups or logins
  • no ads
  • no analytics or tracking
  • no in-app purchases (coins are earned only by playing)
  • no chat, links to social media or sharing features

What is saved, and where

The game saves player names, toys, coins, badges and scores so they are there next time. This is stored only on the device you play on. It is never sent to us or to anyone else, and we cannot see it. Player names are whatever you type in (up to 10 letters); they do not have to be real names.

Deleting the app, or clearing the website's data in your browser, erases this saved progress.

The website

The web version of the game is hosted on GitHub Pages. Like most web hosts, GitHub may record technical details such as IP addresses in its server logs when a page is loaded. We do not have access to those logs. See GitHub's privacy statement. The iPhone app does not load anything from the internet while you play.

Children

The game is made for families and young children. Because it collects no personal information from anyone, it collects none from children.

Changes

If this policy changes, the new version will be posted on this page with a new date.
